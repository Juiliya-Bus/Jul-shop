# Jul-shop
## 📐 Спецификации интерфейсов (API & Events)

Для взаимодействия подсистем интернет-магазина **Jul-shop** используются два типа контрактов:
* **Синхронное взаимодействие (REST API):** Полная спецификация методов, запросов и ответов доступна в файле [openapi.yaml](./docs/openapi.yaml).
* **Асинхронное взаимодействие (Event-Driven):** Спецификация топиков, партиций и Kafka Headers доступна в файле [asyncapi.yaml](./docs/asyncapi.yaml).
