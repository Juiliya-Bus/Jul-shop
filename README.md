# Jul-shop
## 📐 Спецификации интерфейсов (API & Events)

Для взаимодействия подсистем интернет-магазина **Jul-shop** используются два типа контрактов:
* **Синхронное взаимодействие (REST API):** Полная спецификация методов, запросов и ответов доступна по ссылке [OpenAPI Specification](https://github.com/Juiliya-Bus/Jul-shop/blob/main/API/API_Swagger).
* **Асинхронное взаимодействие (Kafka):** Спецификация топиков доступна по ссылке [AsyncAPI Specification](https://github.com/Juiliya-Bus/Jul-shop/blob/main/Kafka/AsyncApi%20eventld).
